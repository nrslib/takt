1. 作ったもの・置き換えたもの

src/app/daemon-turn/index.ts
  Node IPC 専用入口。IPCなしの起動を拒否する。
  initialize / start_turn / interrupt / result_committed / shutdown と親切断を扱う。
  shutdownの後始末が終わってからIPCを切断する。本物のproviderをテストでは呼んでいない。

src/features/daemonTurn/processRuntime.ts
  プロトコルを送受信双方で検証。launchId、turn、requestIdを照合する。
  initialize完了前にはターンを開始せず、readyまでモデルを呼ばない。
  1子1ターン。結果をresult_committedまで保持し、その間の次ターンを拒否する。
  子がAbortControllerを持つ。中断のchangeを保持し、通常終了の遅着を中断結果へ混ぜない。
  保留状態要求は32件 / 1 MiB、単一メッセージは1 MiB、進捗は16 KiB。
  要求・返信にprocessRequestBytesを使い、送信中のメッセージ数と合計バイト数も制限する。
  shutdown / 切断では状態要求の待ちを解放し、初期化、実行、MCPの後始末を待つ。

src/features/daemon/turnProcessHost.ts
  createTurnProcessHost({configDirectory, bus, onError}) が TurnRunner を実装する。
  spawnManagedProcess + Node IPC。起動先は dist/app/daemon-turn/index.js の固定URL。
  本番ホストにtsxや旧CLI入口へのフォールバックはない。ビルド済み成果物を使う。
  会話ごとに子を起動・再利用。設定ディレクトリをcwdとTAKT_CONFIG_DIRに指定する。
  Slack接続用トークンを子へ渡さない。
  ready待ち30秒、中断猶予5秒、shutdown猶予5秒。テストは実時間を合否に使わない。
  error / exit / disconnect / IPC送信失敗を監督。終了通知とexitは一度の終端にまとめる。
  IPC切断だけでは枠を解放せず、強制終了とプロセスグループの後始末を確認する。
  自然終了時にも残ったprovider / MCPの子孫を後片付けする。
  detachedなautoRunは別グループなので、この終了対象に含めない。
  保存確認の送信に失敗した場合、dispatcherが選択した次ターンは旧子の終了後に起動する。
  closeは全所有プロセスの終了と全終端のbus通知完了を待つ。
  初期化失敗、異常終了、状態保存失敗でモデルを自動再実行しない。

src/features/manager/conversationService.ts
  旧createConversationServiceは削除し、createConversationTurnService(configDirectory,runtime)へ置換。
  受付、配送、会話ストアへの書込、旧キュー、旧schedulerを持たない。
  文脈構築、発言ごとのagentOverrides、同一会話のsession、提案、承認、回答、ゴール操作を実行。
  人の発言とイベントは同じruntime / sessionを使用する。イベント専用executorはない。
  予約保存の返信後にゴールを作成し、返信された最新versionを終了changeに使用する。
  登録失敗・中断時は、保存済み予約を残して同じgoalIdで明示的に回復できる。
  イベントは対象repositoryを確認し、goalの制約を権限判定へ渡す。
  paused / abortedなgoalのイベントではモデルを呼ばない。
  イベントの応答を新しい登録提案にはしない。workspace変更の通知も子から進捗として返す。

src/features/daemonTurn/{conversationState,turnContext,toolScope}.ts
  会話の途中保存はsave_conversationだけ。ConversationStoreを子から読み書きしない。
  条件付き保存のversionを取り込み、最終変更にも同じ最新versionを使う。
  業務文脈とゴールの要約を子で構築する。
  TurnToolScopeはターン中のMCP処理を追跡し、親の取消信号を道具へ渡す。
  ターン終了時に新しい道具処理を拒否し、既存の道具処理の後始末を待つ。

manager runtime / managerMcp / managerMcpConnection / turnExecutor、共通MCP server
  managerの組込みMCPは子内のHTTP接続に統一。旧stdio分岐とprepareManagerMcpを削除。
  ユーザー指定のMCP接続設定は保持する。
  goal実行用の道具の公開条件と、現在ターンの認可情報を別に保持する。
  PR mergeは現在のdirector_messageのoperationIdに照合する。
  会話ファイルのrunning / lastSpeakerへの依存を除去。
  goal読込中にターンが終了・変更・中断した場合も、副作用の直前に現在値を再照合する。
  人の発言にagentのspeakerを付けても、director_messageの認可にはならない。

director runtime / MCP、daemonTurn/turnBusiness.ts
  自己IPCによるtell_managerとDirectorNotificationStoreへの直接書込を除去。
  伝言先の業務上の認可を子で確認し、get_deliveryのID/assignmentも照合する。
  accept_director_message / notify_directorの永続応答を待つ。
  通知subjectのkeyは固定プロトコルの128文字上限に収まる安定したSHA-256へ変換する。
  Slack配送は子で行わない。directorの道具処理もターン終了前に待つ。

src/features/daemonTurn/{retirePatrols,reconcileLostRun}.ts
  子のinitializeでassignmentの受け箱に残るpatrolを削除し、モデルを呼ばず処理済みにする。
  他の未処理イベントは残す。
  run_process_lostはgoal-execution / tasksロック内でstatus、goal、runSlug、executionId、
  PID、開始時刻、生死を再確認してからfailedへ変更し、completionを記録する。
  EPERMや照会不能は死亡扱いにせず、通常完了や新しい実行世代を上書きしない。

巡回設定
  manager.patrol_interval / director.patrol_intervalを型、strict schema、解決、
  global/project読込・保存、traced schemaから削除。
  残っている旧設定はschemaで拒否する。互換の読み替えは追加していない。
