Do not start a new broad review. Treat only the latest reviewer reports from the immediately preceding round under the Report Directory as submissions. Inspect current code, requirements, plans, and execution evidence only as needed to decide those submissions.

For each concern, evaluate the technical claim, concrete failure condition, evidence, and reason remediation is required now separately. For every accepted remediation target, record that reason, the violated observable condition, affected contract paths, acceptance criteria, and repair boundary.

Use earlier decisions and history only to match problems with the same cause, violated condition, and acceptance criteria. Do not treat them as current submissions or recreate repair work when the latest reports do not submit a current problem.

Record a complete decision for every submitted concern and the consolidation target for concerns with the same cause. Base the result on current evidence and the adjudication criteria rather than reviewer vote counts. When a concern cannot be decided, state the unresolved premise instead of excluding it by assumption.
