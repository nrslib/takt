# CI investigation
- Target PR, HEAD, run, attempt, job, failed check and references
- Failed test names, assertions and relevant log contents (or evidence that tests never started)
- Cumulative diff and related code examined, with locations
- Cause, repository/external location, supporting and contradicting evidence
- Root fix appropriateness and the causal connection to the failure
- Missing evidence and permission failures
- Fix rounds, rerun count, verdict and summary matching the structured output
