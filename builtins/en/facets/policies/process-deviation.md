# Past process deviations

Judge current artifacts and evidence closing acceptance criteria.

- For past departures from work instructions (commands, verification scope, assignments, order), record only facts and the absence of effects if all hold. Do not fail, mark incomplete, replan, or stop work:
  - Rework cannot undo the action
  - No result remains in artifacts or external state (sent/published content, external data, costs)
  - Evidence closing acceptance criteria observes current code under specified conditions
  - The departure has stopped
- Otherwise, judge normally. Revert or repair artifact results (out-of-scope edits, unrequested dependencies, deleted tests). Recover or confirm remaining external effects; do not return code solely for a process departure. Exclude evidence from other versions or configurations; retain necessary verification.
- Violations of required boundaries (confidentiality, external operations, permissions) are not work-process departures. Judge normally.
