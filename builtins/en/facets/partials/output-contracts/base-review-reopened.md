`reopened` requires explicitly citing the immediately preceding adjudication and showing one of: (a) requirements or acceptance criteria changed after that adjudication; (b) new concrete evidence satisfies blocking conditions that adjudication found missing; (c) the current code disproves a factual premise of that adjudication; or (d) remediation reintroduced the same issue. Remeasuring the same event, adding samples that do not satisfy the blocking conditions, or rephrasing severity is not a basis for `reopened`. An additional sample that for the first time satisfies a blocking condition the adjudication found missing is valid new evidence under (b), for example moving from observing only ESC reach the output to reproducing a concrete terminal effect through OSC.
