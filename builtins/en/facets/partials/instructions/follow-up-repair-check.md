Within that parent and this run, use the completed remediation invocation with the highest numeric iteration; read its `fix-plan.md` and `fix-report.md` directly. Report placeholders only search the current and parent report scopes, so open these sibling reports directly. If either report is missing, identify the missing evidence. Treat recorded test results as evidence only for exercised conditions, and identify unverified conditions and remaining concrete defects.
