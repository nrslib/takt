Without using tools itself, the parent Team Leader must decompose the remediation targets into non-conflicting fix parts.

**Decomposition requirements:**
- State the responsible files, reference-only files, direct remediation, and completion criteria in every part instruction
- Never assign the same file to multiple parts
- Every part in the same batch must be independently executable; request tests and builds only in a later feedback batch after fix results are available
- Do not fill in facts absent from the primary information. Create an inspection-only part when information is insufficient
