## Requirement Scenario Verification

Enumerate every requirement scenario from the plan, cross-check the test report's correspondence table against the actual tests, and confirm each scenario has a corresponding test whose inputs and assertions verify the scenario's observable result and whose latest execution evidence comes from the current diff and passes. The absence of scenario IDs in code is not an issue. Do not treat table entries themselves as coverage evidence: locate the referenced test declaration inside the listed file for each scenario row and check its concrete inputs and assertions against the scenario's Given/When/Then. Treat missing rows, references to nonexistent tests, mismatched inputs or assertions, tests unexecuted via skip/todo, failing tests, and a plan lacking requirement scenarios despite a qualifying completion contract (structured-input classification/transformation or identifier generation) as merge-blocking issues.
