## Requirement Scenario Test Mapping

When the plan contains requirement scenarios (`SCN-` IDs), map each scenario to at least one primary test. Do not write scenario IDs in code (test names or comments). Add one row per scenario to the test report's contract-to-test table: the parent completion contract ID in the "Contract ID" column, the scenario ID and its observable result in the "Observable Contract" column, and both the existing test file path and the test declaration name in the "Test" column.
