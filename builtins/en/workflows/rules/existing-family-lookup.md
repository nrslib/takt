**Lookup of existing remediation units:**

Before writing review-resolution.md or supervisor-validation.md, inspect the latest review reports, review-resolution.md, and carried recurrence records under the Report Directory.

Merge a finding into an existing Actionable Families row when its cause, violated observable condition, and acceptance criteria are the same. Preserve the finding's original ID, then add the path checked now and the evidence that supports using the same remediation unit. Keep a problem in a separate remediation unit when any of those differs.
