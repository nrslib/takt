既存の要件と受入条件は変更せず、最新の計画、実装、テスト、レビューレポートを確認して、実装方針を再定義してください。

Report Directory 内の最新レポートを現在の指摘と実行結果の正本として扱ってください。

Report Directory の `subworkflows/` 配下も確認し、直近の独立レビューの最終判定レポート `review-resolution.md` を確認してください。同じ現行実装・検証証跡・外部制約に対して既に BLOCKED と判定され、その後に結果を変える実装・証跡・環境の変化も新たな有効なプロジェクト内作業もなければ、未確認の要件と必要な外部操作を保持して外部待機とし、同じ独立レビューへ再投入しないでください。レビューが未実施か、結果に影響する変化や新たな有効な作業がある場合は、現在の実装と証跡に対する次の作業またはレビュー要否を判断してください。

実装・再実装から外部制約と未完了義務を受け取った場合、それは直ちに停止する理由ではありません。現行計画で実行できる具体的なプロジェクト内の作業があるかを、試行履歴と確認済みの制約から確認してください。環境制約による検証の未確認だけが残る場合は証跡と外部検証義務を保持してください。不可欠な外部操作・回答待ちだけが残る場合、または要件が両立しないと確認できた場合は、実行可能な作業があるかのように計画せず、その根拠と残作業を計画へ記録してください。
