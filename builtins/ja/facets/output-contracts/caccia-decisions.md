`caccia-decisions.json` には有効な JSON 配列だけを書きます。Markdown のコードフェンスや前後の説明文を付けません。

タスクで渡されたすべての `thread_id` について、重複・余分な項目なしで判断を1件ずつ返します。各項目の形式:

```json
[
  {
    "thread_id": "渡された thread ID をそのまま記載",
    "valid": true,
    "reason": "どのコード契約に反し、何を変更したか"
  }
]
```

`valid` は JSON boolean、`reason` はコード上の根拠を含む空でない文字列にします。今回修正した妥当な指摘だけを `valid: true` とします。不具合ではない指摘は `valid: false` とし、理由を記載します。古いスレッドや妥当でない指摘も含めます。コメント、返信、その他のスレッド本文はレポートに含めません。
