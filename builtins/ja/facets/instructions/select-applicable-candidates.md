変更ファイル名ではなく、変更内容とレポートを選択の根拠にする。対象エージェントのプロンプトが提供されている場合は、それも根拠にする。各入力を制御する主体、入力が越える信頼または権限の境界、入力が到達する処理や資産を判定する。候補は description の条件に該当する場合だけ選び、該当する候補はすべて選ぶ。最新の review-resolution.md に候補が提出した未解消の actionable finding が残っている場合は、その候補の description が該当しなくても選び続ける。follow-up のレポートがその finding を解消済み、統合済み、または対象外として明示的に記録するまで続ける。どの候補にも該当しなければ空配列を返し、既定では選ばない。入力が欠落または切り詰められていて非該当と判定できない場合は、該当し得る候補をすべて選ぶ。
