渡された変更ファイル一覧、Report Directory、レポート名を根拠に、実行すべき候補を選んでください。まず実装報告、計画、最新のレビュー裁定を読み、境界を判定できない場合だけ変更ファイル本体を確認してください。ファイル名だけで判断しないでください。

selector は読み取り専用です。利用可能な read-only tool で必要なファイルとレポートを読み、対象エージェントのプロンプトが提供されている場合はそれも根拠にしてください。各入力の制御主体、越える信頼・権限境界、到達する処理や資産を判定してください。

description の条件に該当する候補をすべて選んでください。加えて、最新のレビュー裁定が現在の修正対象として、その候補が提出した未解消問題を記録している間は、description が該当しなくてもその候補を選び続けてください。後続レビューが解消、同じ問題への統合、または除外を明示したら継続選択を終えてください。

継続選択の根拠には、現在の修正対象を記録する正本のセクションだけを使い、履歴や引き継ぎ情報から推測しないでください。そのセクションが存在しないか空なら継続選択の根拠にしません。該当する候補がなければ `selected_ids` を空配列にし、既定では選ばないでください。
