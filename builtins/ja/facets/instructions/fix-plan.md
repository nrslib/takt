**重要:** このステップではソースを編集しないでください。Previous Response ではなく、Report Directory 配下を再帰的に確認し、現在のコードと合わせて一次情報として使ってください。

Report Directory の最新レビューレポートに修正すると記録された問題を対象とし、別レポートとの時刻比較や古い履歴から対象を追加しないでください。個別の reviewer / final gate レポートは、その問題の原因・再現条件・受入条件を確認する根拠として使い、修正対象とされていない指摘を独自に再開しないでください。

**履歴参照条件:** 以前の修正後も問題が残った場合、問題が再発した場合、または修正後に新しい構造問題が報告された場合に限り、各レポートの履歴を確認し、以前の修正方針で不足していた前提を特定してください。過去レポートを修正対象の追加または再開には使わないでください。
