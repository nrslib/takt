**重要:**
- 編集前に、修正計画を現在のコードと Report Directory の根拠へ照合する
- 計画にある修正単位を容易なものだけ選ばず、同じ欠陥 family の全経路へ適用する
- 計画に不足や矛盾がある場合は部分修正を始めず、根拠を示して「修正計画の見直しが必要」と報告する
- タスク全体の要求や設計を再定義しなければ進められない場合は、「判断できない、情報不足」と根拠を報告する

**やること:**
1. 計画の実施順序に従って全修正単位を実装する
2. family ごとの回帰テストを追加または更新する
3. 変更後のコードで全対象経路と受入条件を再確認する
4. 最後の変更後に、計画とプロジェクトが要求する品質ゲートをすべて実行する
