現在の計画と Report Directory 内の implementation-report.md（存在する場合）を照合し、未完了の必須作業から再開してください。前回のレポートは現在のコードと照合するための証跡であり、完了の宣言だけを根拠にしないでください。

- 計画が有効なまま作業や検証が残る場合は、その残件を実行してください。計画の変更が必要だと判断する場合は、成立しなくなった前提・範囲・方法と現在の根拠を特定してください。
- 必須品質ゲートは、対象コード・テスト・設定・依存・実行環境が結果取得時から変わらず、実行コマンド、正常終了、観測結果を追跡できる成功証跡があれば引き継げます。実行ごとの再検証が明示されている場合はそれに従ってください。証跡がない、同一性を確認できない、失敗・未実行、または変更が結果へ影響する場合は、該当する検証を実行してください。
- 引き継ぐ結果は元の実行記録と対象の識別情報をレポートに残し、今回実行した結果と区別してください。次のレポートにも有効な証跡を保持してください。新たなレポートディレクトリで見つからない結果を成功と推測しないでください。
- 未完了の場合は、今回増えたコード・証拠、残る義務、次に実行する具体的な作業を記録してください。同じ作業を繰り返すだけなら、前回と何を変えて切り分けるのかを示してください。実行可能な次の手段がない場合は、その根拠と外部操作または両立不能な条件を記録してください。
