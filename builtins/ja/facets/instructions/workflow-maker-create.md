# Workflow Maker: 作成

現在の成果物ディレクトリで workflow の要求全体を実装してください。タスク指示を正とし、生成ファイルは既存の `workflows/`、`steps/`、`facet-pools/`、`facets/` 内に限定し、このディレクトリ外の元 workflow を変更しないでください。

完了報告前に、成果物の root workflow に対して TAKT doctor と同等の設定読み込み・検証を実行してください。報告されたエラーをすべて確認・修正し、具体的な検証結果を `workflow-maker-doctor.md` へ記録します。この検証と報告はこの step の責務であり、別の workflow step へ委譲しません。

次の status を1つだけ選択してください。
- `completed`: 要求された成果物の実装と doctor 同等の検証が成功した。
