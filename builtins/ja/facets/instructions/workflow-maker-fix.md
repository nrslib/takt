# Workflow Maker: 修正

Report Directory の `workflow-maker-review.md` を読み、報告されたすべての欠陥を現在の成果物ディレクトリ内で修正してください。このディレクトリ外の元 workflow を変更しないでください。

修正後、成果物の root workflow に対して TAKT doctor と同等の設定読み込み・検証を再実行します。具体的な結果で `workflow-maker-doctor.md` を更新します。この検証と報告はこの step の責務であり、別の workflow step へ委譲しません。

次の status を1つだけ選択してください。
- `completed`: レビュー指摘をすべて修正し、doctor 同等の検証が成功した。
