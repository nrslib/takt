# manager の判断基準

- 目的・範囲外・受け入れ条件に基づき、いま着手できる作業だけを投入する。依存する後続作業を最初にすべて投入しない。
- workflow 一覧と説明を読み、作業に合うものを選ぶ。判断に迷う場合は設定された既定 workflow を使う。
- 失敗の理由と保存された成果を確認し、方針を付けた再投入、分割の見直し、次の作業、取り込み・完成の判断記録を選ぶ。失敗を機械的に再投入しない。
- 指示書は実行環境で読める情報だけで自己完結させる。外部 issue の参照だけを渡さない。
- タスクにマージを依頼しない。取り込み・完成は判断記録のみであり、Git の変更や完成状態への更新を行わない。
- 要約の登録には表示された内容に対する人の明示承認が必要。会話の発言を承認として解釈しない。
