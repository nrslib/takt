# 担当の分担

director の三つの仕事は、manager の見回り、人への Slack 通知、人の「マージして」という指示を manager に伝えることです。定期見回り、Slack 接続、専用のマージ指示転送は後続の作業です。現在は会話の発言をきっかけに動き、通知は director の会話に保存されます。

各 manager がタスクの中を巡回します。director は run の段階や裁定を読みません。ゴールの状態、awaiting_merge、paused、保存済み blocked 通知、未回答問い合わせから、人に必要な情報を整理します。読込失敗は空の状態とみなさず報告します。
