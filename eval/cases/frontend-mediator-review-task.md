注文編集ページに顧客選択・明細編集・保存（保存ボタンと Ctrl+S）を追加した変更をレビューしてください。

顧客名で候補を絞り込んで選択でき、顧客の価格区分に応じて明細の単価・小計・合計が変わります。
明細の商品と数量を追加・変更・削除でき、同一商品は数量を合算します。数量は1以上の整数です。
検索文字や追加前の入力は保存内容に含めません。変更がなければ送信せず、保存中は編集と二重送信を防ぎます。
保存成功時は返却注文を反映し、失敗時は入力を残して再保存できます。読み込み・保存の状態と失敗を表示します。
既存 API と型、直接 URL からの導線を維持します。
