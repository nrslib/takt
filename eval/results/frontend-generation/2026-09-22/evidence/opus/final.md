問い合わせ返信画面を作りました。`npm run build` は成功しています。ただし、このセッションでは画面の動作を実際には一度も確かめられていません。確認用スクリプトの実行とブラウザでの操作が、どちらもできなかったためです。

**確認できなかったこと**
- **確認用スクリプト（`verify/machine.check.ts`）:** 保存・切替・失敗と再試行・連打の回数などを確かめるために書きました。`npx`、`node`、`npm run verify` がどれも実行許可を得られず、**未実行**です。`npm run verify` で実行できます。この実行のために `package.json` に `verify` スクリプトを追加しました。
- **ブラウザでの手動確認:** フォーカスの移動、ダイアログ表示中に背景が操作できないこと、読み上げは試していません。コードを読んで確かめただけです。

**設計の要点**
- **判断の置き場所:** 保存するか・切り替えるか・拒否するかは、状態を受け取って次の状態を返す一か所（`src/screens/inquiryDeskMachine.ts`）で決めます。保存処理を始めるのは `src/screens/useInquiryDesk.ts` だけで、保存を受け付けたときにだけ動きます。
- **連打の扱い:** 同じ瞬間に何度押されても最新の状態で判断するので、保存処理は一回だけ行われます。
- **保存の入口:** ボタンも Ctrl+Enter / Command+Enter も、同じフォーム送信を通ります。
- **ダイアログ:** 操作説明と切替確認は、ブラウザ標準の `<dialog>` で開きます。開いている間は背景を操作できず、閉じると開いたボタンへフォーカスが戻ります。
- **保存中のボタン:** 押せない状態にはせず、押されたら受け付けなかった理由をその場に表示します。
- **状態の持ち方:** 検索語だけは一覧の中に持ち、選択中の問い合わせや編集中の返信などは画面側で一つにまとめています。
