# 実装課題：二つの宛先へのメッセージ送信

React、TypeScript、Viteで日本語の小さなWebアプリを作ってください。依存はインストール済みです。

- 同じ画面で、二つの異なる宛先へのメッセージをそれぞれ入力し、送信できる。
- 各入力欄には、送信ボタンとCtrl+Enter / Command+Enterによる送信がある。通常のEnterは改行する。
- 空白だけのメッセージは送信せず、理由を表示する。
- 送信処理は外部サービスを使わず約1秒で完了させる。同じ宛先へ処理中に連打しても一回だけ送る。処理中はその宛先の入力を変えられない。
- 一方を送信している間も、もう一方の入力と送信はできる。送信結果には実際に送った本文を表示する。
- 入力を消す操作は、その宛先の欄の中に確認メッセージを出し、破棄するか編集に戻るか選べる。これは画面全体を覆うダイアログではない。
- 確認している宛先の入力や送信は止め、編集に戻れば元の入力を残す。もう一方の宛先は確認中も使える。
- 各宛先には「次の送信を失敗させる」操作と、受け付けた送信回数を表示する。失敗は一度だけ起こり、本文を保持して再試行できる。
- ヘッダーと二つの入力欄から、同じ操作説明ダイアログを開ける。閉じたら元の操作を続けられる。
- URLによる状態保持、再読込後の保持、外部APIは不要。上記機能に絞る。

$coding を参照しないでください。SKILL.md、その他のスキル、AGENTS.md、過去の会話、他プロジェクト、評価問題や模範解答を参照しないでください。プロジェクト内の仕様、criteria、インストールされた依存の実装・型は参照できます。Web検索は不要です。subagentは使用しないでください。

コンポーネントの分割、状態の置き場所、操作の処理方法、識別子の名前は、自分で設計してください。設計パターンを説明するだけでなく、実行できるコードを完成させてください。不要な機能は増やさないでください。
