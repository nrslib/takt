# replydesk — 問い合わせ対応

React + TypeScript + Viteで作成した、問い合わせへの返信を編集する小規模なデモアプリです。外部サービスは使わず、保存はブラウザ内の非同期処理で再現しています。

## 起動方法

依存関係がインストール済みの場合は、次のコマンドで起動できます。

```bash
npm run dev
```

表示されたローカルURLをブラウザで開いてください。ビルドは次のコマンドで実行できます。

```bash
npm run build
```

## 操作方法

- 左側の一覧から問い合わせを選ぶと、問い合わせ本文と保存済みの返信が表示されます。
- 返信欄を編集し、「返信を保存」を押すか `Ctrl + Enter` / `Command + Enter` で保存します。通常の `Enter` は改行です。
- 保存処理は約1秒かかります。保存中は同じ保存の連打と問い合わせの切り替えを受け付けず、状態と理由を表示します。
- 空白だけの返信は保存できません。保存済みの返信へ戻す場合は「保存済みに戻す」を押します。
- 未保存の編集がある状態で別の問い合わせを選ぶと確認ダイアログを表示します。「変更を破棄して切り替える」または「切り替えをやめる」を選べます。
- 「次の保存を失敗させる」を有効にすると、次に受け付けた保存だけが失敗します。失敗後も編集内容は残り、再度保存すると成功できます。
- 「受け付けた保存」は、実際に受理した保存処理の累計です。保存中の連打や入力不備による拒否では増えません。
- ヘッダーと返信欄の「操作ガイド」から同じダイアログを開けます。検索欄では件名・名前などを検索でき、該当なしも表示します。

## 選んだ設計とcriteriaとの関係

- `App`をRootとして、`Header`、`InquiryList`、`InquiryDetail`、`ReplyEditor`、各ダイアログを表示部品に分けています。表示部品は値を描画し、操作の意図をcallbackで上位へ通知します。
- `useInquiryEditor`を画面のMediatorとして使い、選択対象、草稿、保存状態、未保存切替確認、保存結果を一元管理しています。ボタン・フォーム送信・キーボードショートカットは同じ保存handlerを通ります。
- `knowledge-gui.md` / `policies-gui.md`に合わせ、Rootから表示と操作処理をたどれる構成にし、保存中の競合操作を拒否して理由を表示します。
- `knowledge-frontend.md` / `policies-frontend.md`に合わせ、適切なHTML要素、label、状態表示、検索結果の空状態、モーダルの背景操作抑止を実装しています。URL・外部通信・永続化は仕様に合わせて追加していません。
- `knowledge-react.md` / `policies-react.md`に合わせ、共有状態を画面側に集約し、派生値は描画時に計算しています。保存のタイマーはhandlerで開始し、結果だけをstateへ反映しています。
