# Application configuration

JSON設定ファイルからアプリケーションの設定を読み込みます。省略された項目には既定値を使い、ファイルで指定された値を優先します。

The loader reads application settings from a JSON file. Omitted settings use defaults, while values specified in the file take precedence.

`node --test` で設定読み込みのテストを実行できます。
Run `node --test` to test configuration loading.
