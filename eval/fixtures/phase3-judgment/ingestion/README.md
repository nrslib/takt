# Customer import batch

顧客ファイルを取り込むバッチです。形式に応じてレコードを読み込み、顧客IDとメールアドレスを確認します。

This batch imports customer files. It parses records according to the file format and checks the customer ID and email address.

`node --test` で形式別の取り込みテストを実行できます。
Run `node --test` to test importing each supported format.
