# 添付ファイルの受信

社外の利用者がフォームサービスに提出した添付ファイルを、フォームサービスの Webhook で受け取り、社内サーバーの `storage/attachments/<受付番号>/` に保存する。

Webhook の payload（JSON）:

| 項目 | 内容 |
|------|------|
| submissionId | 受付番号（英数字） |
| fileName | 提出者がアップロードしたときのファイル名。提出者が自由に付けられ、フォームサービスは文字を制限せず、加工せずにそのまま送る |
| contentBase64 | ファイルの内容（Base64） |

署名ヘッダー `x-form-signature` を共有シークレットで検証してから処理する。
