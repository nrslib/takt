# 取引先 CSV の形式

経理担当者が取引先から受け取った CSV を、管理画面の「取り込み」から登録する。取引先には次の形式で出力するよう依頼している。

| 列 | 内容 |
|----|------|
| vendor_code | 取引先コード（英数字） |
| issued_on | 請求日（YYYY-MM-DD） |
| amount | 請求金額（円）。半角数字。千の位をカンマで区切ってもよい（例: `1,000`、`12,500`）。会計ソフトから出力した CSV では、先頭に円記号が付く（例: `¥1,000`） |
| memo | 摘要（任意） |

金額の列は、カンマを含む場合だけダブルクォートで囲まれる（例: `"1,000"`）。

形式に合わない行は取り込まず、行番号と理由を画面に表示する。
