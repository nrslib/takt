# Manager registration

When a person provides the absolute path of an existing Git repository, the director can register a manager for it. Registration is initiated only from a human message turn; watch observations and agent turns do not authorize it. The repository argument is validated as an absolute path to an existing Git repository.

人が既存のGitリポジトリの絶対パスを伝えると、directorはそのリポジトリのmanagerを登録できる。登録は人のmessage turnからだけ開始する。watcherの観測やagent turnは登録を認可しない。repository引数は既存のGitリポジトリへの絶対パスとして検証する。
