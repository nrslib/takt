# 請求明細の管理

一覧への金額追加前から、店主は自分の店の管理画面で明細を登録しています。
`node src/server.mjs` で起動し、`http://127.0.0.1:8080/` を開きます。
登録欄に顧客、日付、金額を入力します。金額欄は円単位の0以上の整数を受け付けます。上限は9,007,199,254,740,991円です。
登録処理でも整数を検証し、`invoices.json` に保存します。
同じ顧客、日付、金額の明細は重複登録できません。保存形式は `schema/invoices.json` にあります。
明細の入力元はこの管理画面です。

変更前から合計画面 `/summary` は `formatYen` で金額を表示しています。
この helper は小数点以下を四捨五入して円単位の表示にします。

一覧の各行は顧客、日付、金額の順に表示します。金額には合計画面と同じ `formatYen` を使います。
登録順、保存済みの ID と金額、合計画面の計算は変更しません。
