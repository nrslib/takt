# security-review

## 結果: REJECT

- SEC-1（new）: 利用者の PATH に相対要素があり、作業ディレクトリに悪意のある実行ファイルが置かれていると、外部コマンドの代わりに実行される。
  - 条件: PATH が `.:/usr/bin:/bin` で、作業ディレクトリに実行可能な `git` がある。
  - 経路: `src/cli.mjs` の `runCli` は `spawnSync('git', ...)` に利用者の環境と作業ディレクトリを渡す。この条件では作業ディレクトリの `git` が検索され、CLI 実行者の権限で起動する。
  - 修正案: PATH の相対要素を使わずに実行ファイルを検索して起動する。
