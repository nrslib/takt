# 下書き送信画面の変更要求

送信成功時だけ下書きを確定して完了画面へ移る。通信断または一時的なサービスエラーの場合は、エラーを表示し、編集中の画面、下書き、配送先の選択を維持する。既存の経路廃止通知では接続を解除する。

今回の修正対象 TEST-DELIVERY-001 は、新しく追加した画面の失敗分岐のテスト不足。受入条件は、送信が失敗した際のエラー表示、下書きと配送先の選択の保持、完了画面へ移らないこと、確定処理を呼ばないことをテストすること。

配送クライアントの既存の内部構造は変更対象ではない。通信断・一時的なサービスエラーの後も、同じ画面からの再送は元の配送先へ届くこと。検証方式は指定しない。
