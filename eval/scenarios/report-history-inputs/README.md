# 現在レポートと履歴の読み取り評価

ビルド後に `node eval/scenarios/report-history-inputs/run.mjs [model]` を実行する。

peer-review の裁定結果を修正計画へ引き継ぐ入力と、development-remediation の cycle 内の修正報告を参照する監視用の入力を使う。入力の参照を解決し、その時点の内容を保存してから、InstructionBuilder と runAgent に渡す。provider を呼び出す直前の入力を取得し、既存の読み取り専用モデル実行器へ渡す。役割ごとに作業ディレクトリを分け、現在のレポートの省略部分と履歴だけに、実行ごとに異なる照合用の情報を置く。

成功とするには、正常終了した読み取りコマンドの出力に両方の照合用の情報が現れ、比較結果が現在の修正対象 B だけを保持し、A の完了を進捗と判断している必要がある。モデルの自己申告だけでは成功と判定しない。

モデルの実行とセッションの監査は、リポジトリ外の非公開の一時領域で行う。評価専用の HOME・CODEX_HOME を作り、認証用の auth.json だけを渡す。個人の設定・記憶・指示・skills や任意の環境変数は引き継がない。認証の準備に失敗した場合は評価を失敗とし、元の HOME で続行しない。一時領域は成功・失敗・中断のいずれの場合も削除する。

`eval/results/report-history-inputs/` へ保存するのは、公開用に変換した入力、比較結果、実行条件、保存したレポートと読み取りの証拠である。パスは評価成果物を基準とする相対パスへ変換する。モデルの応答からは、照合用の情報・現在の対象・進捗に関する4項目だけを保存する。コマンドの記録は、対象レポートを読む実際のコマンドのうち正常終了したものと、照合用の情報を含む資料行の出力抜粋に限る。ローカル指示の出力、加工前のモデル記録、認証情報は公開しない。失敗時もエラー本文をそのまま保存せず、失敗・中断の別と証拠の不足を記録する。

trace の `executedPromptHash`・`executedResponseHash` は実行時の値、`promptHash`・`responseHash` と `publication.json` は変換後の公開物の値を表す。保存したレポートの読み取り証拠には、公開後の本文ハッシュを付ける。

複合コマンドに対象外の操作がある場合は、実際に実行された読み取り部分を`commandExcerpt: true`として抜粋する。`exitCodeScope`が示す終了値は記録されたコマンド全体のもので、抜粋部分の独立した終了値とは扱わない。元のコマンドはハッシュだけを保持する。

既存3結果の情報除去には`node eval/scenarios/report-history-inputs/sanitize-existing.mjs`を使う。過去結果の`originalPass`と、公開後に残った証拠の`pass`を区別し、隔離後の新規実行としては扱わない。公開物の対応・ハッシュ・除去結果は別途全件確認する。

モデルを呼び出さずに隔離と公開用の保存処理を検証するテストは、`npm run eval:prompts:report-history-inputs:contracts` で実行する。
