# 汎用性の判定

再発を防ぐための文面が、別の要求にも同じ形で当てはまる判断規則になっているか確かめる。

## 原則

| 原則 | 基準 |
|------|------|
| 原則 | 元の事例がどの原則に当てはまるか説明できる |
| 言葉の選び方 | 元の事例に特有の言葉を主語や条件に残さない |
| 別のドメイン | 元の事例と無関係な2つ以上の状況へ同じ形で適用できる |
| 規則の強さ | 別の状況にも使えるように書き直しても、禁止したい読み替えを防げる |
| 当てはまらない要求 | 規則が当てはまる要求と対にする |

## 5つの問い

各問いに判定と根拠を残す。規則は「規則が当てはまる条件 → 禁止すること → 必ず行うこと」の形で書く。規則が当てはまらない要求も対にして評価する。

| 問い | REJECT となる状態 |
|------|--------------------|
| この規則はどの原則に当てはまるか | 原則を一文で言えず、事例の言い換えにとどまる |
| 元の事例に特有の言葉が主語や条件に残っていないか | その言葉を別の題材へ置き換えると意味が通らない |
| 別のドメインでも同じ規則が同じ形で当てはまるか | 当てはめるために追加のただし書きが必要になる |
| 別の状況にも使えるように書き直すとき、規則の強さを保てているか | 条件が広がって当てはまらない要求にも適用される、または禁止したい読み替えが残る |
| 当てはまらない要求も対で書いたか | 純粋な変換、新しい結果、再起動後の永続化、既存動作の維持などを、規則が当てはまる要求と区別できない |

抽象的な形容詞を足しただけでは、判断の手順は変わらない。要求文のどの性質に規則が当てはまるのか、どの読み替えを禁じるのか、何を観測し、どう対応する必要があるのかまで確かめる。
