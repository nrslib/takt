# 汎用性の判定

事故の再発防止文を、別の要求にも同じ形で効く決定規則として検証する。

## 原則

| 原則 | 基準 |
|------|------|
| 原理 | 事故が何の原理の一例なのかを説明できる |
| 語彙 | 主語と条件に事故固有の語を残さない |
| 別ドメイン | 事故と無関係な2つ以上の状況へ同じ形で適用できる |
| 強さ | 汎用化しても禁止したい読み替えを防げる |
| 非適用 | 発火しない要求を対にする |

## 5つの問い

各問いに判定と根拠を残す。規則は「発火条件 → 禁止 → 必須対応」と、発火しない側の対で評価する。

| 問い | REJECT となる状態 |
|------|--------------------|
| この規則は何の原理の一例か | 原理を一文で言えず、事例の言い換えに留まる |
| 事故由来の語が主語や条件に残っていないか | 事故の語を別の題材へ置き換えると意味が通らない |
| 別ドメインで同じ規則が同じ形で効くか | 当てはめに追加の但し書きが必要になる |
| 汎用化で薄まっていないか | 条件が広がって誤発火する、または禁止したい読み替えが残る |
| 発火しない側を対で書いたか | 純粋な変換、新規結果、再起動後の永続化、既存動作の維持などの境界を区別できない |

抽象的な形容詞を足しただけでは、判断の手順は変わらない。要求文のどの性質が条件となり、どの読み替えを禁じ、どんな観測・対応を必要とするかまで確かめる。
